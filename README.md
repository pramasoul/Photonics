# Photonics

Carrier-resolved 1D FDTD simulation of second harmonic generation (SHG) in periodically poled lithium niobate (PPLN), running on GPU via CuPy.

![QPM demonstration](ppln_fdtd/docs/figures/fig02_qpm.png)
*Quasi-phase-matched SHG at 1064→532 nm. Left: poling period matched, SH grows coherently. Right: detuned, SH suppressed.*

## What this is

A real-time interactive simulation that lets you watch a laser pulse propagate through a PPLN crystal and generate second harmonic light. You can sweep the poling period, temperature, pulse width, and pump intensity, and see quasi-phase-matching engage and disengage in real time.

The simulation resolves the optical carrier (not just the envelope), which means you see actual electromagnetic field oscillations at ~280 THz and their nonlinear interaction with the χ⁽²⁾ poling structure. This is computationally expensive but physically transparent — every photon of second harmonic is generated by Maxwell's equations, not by a coupled-mode approximation.

## Running

```bash
cd ppln_fdtd
pixi run gl          # OpenGL real-time viewer (recommended)
pixi run mpl         # matplotlib viewer (slower, more portable)
```

Key controls in the GL viewer:
- **Λ slider**: poling period (drag to detune/retune QPM)
- **T slider**: crystal temperature (shifts phase matching via Sellmeier)
- **Intensity**: pump peak intensity in W/cm²
- **ppw**: points per SH wavelength (resolution vs speed tradeoff)
- Scroll to zoom, click-drag to pan

## Requirements

- NVIDIA GPU with CUDA support
- Python 3.10+
- [pixi](https://pixi.sh) package manager (or install dependencies manually: `cupy`, `numpy`, `matplotlib`, `glfw`, `moderngl`)

## Technical note

The development of this simulation uncovered several non-obvious numerical issues in carrier-resolved nonlinear FDTD, documented in detail:

**[Carrier-Resolved FDTD for SHG in PPLN: Development, Learnings, and Limitations](ppln_fdtd/docs/fdtd_technical_note.md)** — covers the two-grid formulation, three coupling approaches (and why two of them fail), the discovery that numerical dispersion mismatch between grids is the dominant error source, and energy/Manley-Rowe conservation.

A PDF version is available: [`ppln_fdtd/docs/fdtd_technical_note.pdf`](ppln_fdtd/docs/fdtd_technical_note.pdf)

To rebuild the PDF:
```bash
cd ppln_fdtd/docs
make pdf
```

To regenerate all figures:
```bash
cd ppln_fdtd/docs
python paper_figures.py
```

## Key findings

- **Coupling formulation must match the host scheme's time order.** The Yee leapfrog is first-order in E; only a first-order nonlinear source (∂P_NL/∂t) accumulates SH correctly. Second-order sources (∂²P_NL/∂t²) are incompatible regardless of their formal accuracy.

- **Numerical dispersion mismatch between coupled grids is the dominant error.** Sub-percent phase velocity errors on individual grids create a parasitic Δk that destroys QPM coherence. A one-time permittivity correction at initialization eliminates this entirely, making conversion ppw-independent.

- **Manley-Rowe conservation requires explicit enforcement.** The MR-matched coupling constant ratio (a factor of 4 from the naive derivation) is necessary but not sufficient; residual drift accumulates over millions of timesteps.
