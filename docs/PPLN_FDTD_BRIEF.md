# PPLN 1D FDTD Explorer — Implementation Brief (Phase 1)

## Goal

Real-time 1D FDTD simulation of second harmonic generation in periodically poled lithium niobate (PPLN). The user watches a fundamental pulse propagate through a crystal and generate second harmonic light, with interactive controls to sweep the poling period and see quasi-phase-matching (QPM) engage and disengage. Runs on an RTX 5090 via CuPy.

## Physics Model (Phase 1: Two-Frequency Envelope)

We do NOT yet implement full broadband dispersive FDTD. Instead, we run two co-propagating 1D FDTD grids — one for the fundamental (ω) and one for the second harmonic (2ω) — coupled by the χ⁽²⁾ nonlinearity. This is simpler to implement, easier to visualize, and already captures the essential QPM physics.

### Grid

- Standard 1D Yee lattice: E_x and H_y fields, staggered in space by Δz/2 and in time by Δt/2.
- Two independent grids: (E1, H1) at refractive index n₁ = n(λ_fund) and (E2, H2) at n₂ = n(λ_fund/2).
- Refractive indices from Jundt Sellmeier equation for 5% MgO:LiNbO₃ extraordinary ray (the standard PPLN material):

  n²(λ,T) = a₁ + b₁·f(T) / (λ² - (a₂ + b₂·f(T))²) + b₃·f(T) / (λ² - a₃²) - a₄·λ²

  where f(T) = (T + 273.15)² - (24.5 + 273.15)², and T is in °C.

  Coefficients (Gayer et al. 2008 for MgO:LN):
  - a₁ = 5.756  
  - a₂ = 0.0983  
  - a₃ = 0.2020  
  - a₄ = 0.0415  
  - b₁ = 2.860e-6  
  - b₂ = 4.700e-8  
  - b₃ = 6.113e-8  

  λ in μm, T in °C. Use T = 25°C as default, make it a parameter.

### Coupling

Each FDTD grid propagates independently at its own phase velocity c/n. The nonlinear coupling is a source term added after the standard linear update:

- E2 gets a source: +α · d(z) · E1² (upconversion, ω+ω→2ω)
- E1 gets a source: +β · d(z) · E2 · E1* (back-conversion, but in real fields E1 is real so this is just β · d(z) · E2 · E1)

where d(z) = d_eff · sign(z) is the spatially varying nonlinear coefficient. For PPLN, d(z) is a square wave with period Λ (the poling period) toggling between +d₃₃ and -d₃₃.

d₃₃ for LiNbO₃ ≈ 27 pm/V. Effective d_eff for first-order QPM = (2/π)·d₃₃ ≈ 17.2 pm/V, but we implement the actual square wave toggling ±d₃₃ so the Fourier harmonics fall out naturally (this is the point — the user sees WHY QPM works, not just that it does).

Coupling constants α, β must be dimensionally consistent with FDTD units. In Gaussian-like SI FDTD units:

  P_NL = ε₀ · χ⁽²⁾ · E²

where χ⁽²⁾ = 2·d (the factor of 2 comes from the d-tensor convention). The source added to the E-field update is:

  ΔE = -Δt/(ε₀·n²) · ∂²P_NL/∂t²

For the two-frequency model, approximate this as:

  ΔE₂ += (Δt · ω₂² · χ⁽²⁾(z) / n₂²) · E₁²  (scaled appropriately)
  ΔE₁ += (Δt · ω₁² · χ⁽²⁾(z) / n₁²) · 2·E₂·E₁

**Important implementation note:** The χ⁽²⁾ coupling is weak in realistic units. To see visible SHG in a manageable grid, either:
(a) use realistic d₃₃ with a long crystal (~10 mm, ~10⁶ cells at λ/20 resolution) — feasible on GPU, or
(b) artificially boost d₃₃ by 10–100× for a shorter crystal with faster visual feedback, and provide a "realism" slider.

Start with option (b) for interactivity; label the boost factor clearly in the UI.

### Grid Parameters

- Spatial resolution: Δz = λ_min / 20 where λ_min = λ_fund/(2·n₂) (resolve the SH wavelength in the medium). For λ_fund=1064nm, n₂≈2.23, λ_min≈239nm, so Δz≈12nm.
- Courant condition: Δt = Δz / (c · S) where S < 1 (Courant number); use S = 0.5.
- Crystal length: start with 0.5 mm = 500 μm → ~42,000 cells. Trivial for GPU.
- Total grid: crystal + vacuum margins on both sides for source injection and absorbing boundaries.
- Target: ~100k–200k total cells.

### Boundary Conditions

Simple first-order Mur absorbing boundary conditions at both ends. No need for full PML in 1D — Mur is 3 lines of code and works fine for this.

### Source

Gaussian pulse modulated at the fundamental frequency, soft-source injected (additive) a few cells inside the left boundary of the fundamental grid:

  E1_source(t) = E₀ · exp(-(t - t₀)² / (2·σ_t²)) · sin(ω₁ · t)

Default: λ_fund = 1064 nm (Nd:YAG), pulse width ~100 fs to ~1 ps (user-adjustable). The second harmonic grid gets NO injected source — all 2ω light must be generated by the nonlinearity.

### viz.py

Matplotlib figure with 3 vertically stacked subplots sharing the z-axis:

1. **Top panel: E-fields** — E1(z) in red, E2(z) in blue, overlaid. Y-axis auto-scales. The fundamental pulse visibly propagates right; the SH signal grows (or doesn't) inside the crystal region.

2. **Middle panel: Poling pattern** — d(z) shown as a bar/step plot (red/blue bands for ±d₃₃). This makes the domain structure visually obvious and connects the spatial periodicity to what's happening in the fields above.

3. **Bottom panel: Spectrum** — Running FFT of E-field sampled at a probe point near the right boundary. Shows the fundamental peak and (when QPM is working) the SH peak growing. Log scale on y-axis.

Below the plots, `matplotlib.widgets.Slider` instances for:

- **Λ (poling period)**: range from 0.5× to 2× the ideal QPM period. Default = ideal QPM period for 1064→532 nm at 25°C. Display current Λ and the ideal Λ_QPM for reference.
- **T (temperature)**: 20–200°C. Shifts n₁, n₂ via Sellmeier → detunes QPM.
- **χ⁽²⁾ boost**: 1× to 200× (log slider). Scales d₃₃ uniformly.
- **Pulse width**: 50 fs to 2 ps.

A text annotation showing: current Δk, coherence length L_coh, and the first-order QPM period Λ_QPM = 2·L_coh.

Use `FuncAnimation` with `blit=True`. Target ~30 fps display; run as many sim steps per frame as needed (auto-calibrate: measure wall-clock per step, fill the frame budget).

### main.py

Minimal: parse no arguments, construct simulation with defaults, construct viz, start animation loop. That's it.

## Defaults and Sanity Checks

- λ_fund = 1064 nm → λ_SH = 532 nm
- At T=25°C: n(1.064μm) ≈ 2.156, n(0.532μm) ≈ 2.234
- Coherence length: L_coh = 1.064 / (4·(2.234 - 2.156)) ≈ 3.41 μm
- Ideal QPM period: Λ = 2·L_coh ≈ 6.82 μm
- With Δz ≈ 12 nm, one poling domain ≈ 284 cells — well-resolved.

Verify: when Λ slider is at the ideal value, SH field should grow monotonically through the crystal. When Λ is detuned by >20%, SH should oscillate and stay small. This is the primary acceptance test.

## What NOT to Include in Phase 1

- No ADE / Lorentzian dispersion (Phase 2)
- No broadband single-grid FDTD (Phase 2)  
- No OPO / parametric oscillation (needs cavity, Phase 3)
- No 2D/3D (never, for this project)
- No waveguide modes or transverse structure
- No GPU-rendered display (matplotlib is fine for now)
